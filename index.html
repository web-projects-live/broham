Game Controls

Player 1 (Big Brother)

  • W - Jump
  • A - Move Left
  • S - Crouch/Block
  • D - Move Right
  • Left Shift - Attack
  • Q - Run

Player 2 (Little Brother)

  • ↑ - Jump
  • ← - Move Left
  • ↓ - Crouch/Block
  • → - Move Right
  • Space - Attack
  • Enter - Run

Game Controls

  • P or ESC - Pause Game
  • R - Restart (when game over)
  • D - Toggle Debug Mode
  • H - Toggle Hitboxes

Click buttons in game to navigate menus
